# device_identity

Reads the per-device identity (`SONIK-<n>`) and provisioning proof-of-possession that the factory
app flashed into the `fctry` NVS partition.

```c
#include "device_identity.h"

if (device_identity_init() == ESP_OK) {
    ESP_LOGI(TAG, "I am %s", device_identity_get());
    const char *pop = device_identity_get_pop();   // secret: never log it; NULL on old partitions
}
```

`device_identity_init()` returns `ESP_ERR_NOT_FOUND` on a device that did not go through the
factory app (e.g. flashed with `idf.py flash`, which leaves `fctry` erased). Decide per product
whether that is fatal; `main` currently logs a warning and carries on.

## The contract

| What            | Value      | Also defined in                                   |
| --------------- | ---------- | ------------------------------------------------- |
| Partition label | `fctry`    | `partitions.csv`, `apps/factory` (looks it up by label) |
| NVS namespace   | `factory`  | `apps/api/src/factory.ts`                         |
| NVS key         | `identity` | `apps/api/src/factory.ts`                         |
| NVS key         | `pop`      | `apps/api/src/factory.ts` (`devices.provisioning_pop`) |
| NVS keys        | `meter_model` (str), `meter_addr` (u8), `meter_baud` (u32), `meter_parity` (str) | `apps/api/src/factory.ts` `METER_KEYS` (`devices.meter_*`); optional |

The image is generated by `packages/nvs-partition` (byte-identical to IDF's
`nvs_partition_gen.py`). Adding more factory data later (certificates, hardware revision) means
more keys in the same namespace: add them in the API and read them here.

To put an identity on a dev board without the factory app:

```sh
printf 'key,type,encoding,value\nfactory,namespace,,\nidentity,data,string,SONIK-DEV\npop,data,string,abcd1234\nmeter_model,data,string,SDM120\nmeter_addr,data,u8,1\nmeter_baud,data,u32,2400\nmeter_parity,data,string,none\n' > /tmp/fctry.csv
python $IDF_PATH/components/nvs_flash/nvs_partition_generator/nvs_partition_gen.py generate /tmp/fctry.csv /tmp/fctry.bin 0x6000
parttool.py write_partition --partition-name=fctry --input /tmp/fctry.bin
```
